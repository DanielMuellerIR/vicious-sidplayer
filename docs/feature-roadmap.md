# Feature roadmap

Updated: 2026-10-16. Baseline: v1.9.26.

This roadmap extends the [feature assessment](feature-opportunities.md). Each stage includes design, implementation and validation.

| Stage | Goal | Status |
|---|---|---|
| 01 | PAL/NTSC-Timing | Completed in v1.9.27 |
| 02 | Hörfolgen, Subtunes und Warteschlange: Core und Mac | In progress |
| 02b | Hörfolgen auf iPhone und HTML5 | Planned |

| 04 | Repeat, Fadeout, Endzeiten und Einschlaftimer | Planned |
| 05 | Verlauf, Lesezeichen und Notizen | Planned |
| 06 | Austausch persönlicher Sammlungsdaten | Planned |

| 12 | Formatkompatibilität und klare Grenzen | Planned |
| 13 | Tastatur, VoiceOver und anpassungsfähiges Layout | Planned |
| 14 | Energie und Zeichenlast | Planned |
| 15 | Gezieltes 6581-Filter-Tuning | Planned |
| 16 | Reale iPhone-Geräteabnahme und Abschluss | Planned |

History will share the library/playlist area as an additional tab. The application remains a single player with one coordinator. Common playback and collection rules belong in the shared core; the HTML5 player remains usable from a local single file.

Playback correctness, large-library responsiveness, personal-data portability and accessibility are acceptance requirements throughout the roadmap. Device-dependent iOS behavior requires real hardware validation.
